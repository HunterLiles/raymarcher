# PSX Style Game

This is a game being made in a custom Vulkan game engine. This engine allows only for compute shaders, uses a custom math library, has a custom caching system for caching SDFs and other things, and finally is just all around made for raymarching in mind as the main rendering method.

The current game being made with this engine to show it off is a PSX old school themed Medieval Fantasy game. Imagine games like Elder Scrolls Daggerfall or other older games like that but with systems and computation ability of todays computers.
